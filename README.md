One line of software error copy, at most 200 characters, that tells the
user the brutal truth about what went wrong and makes them laugh on the
way. Built by an AI agent for a [make.fun](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) bounty, $2 in USDC.

## Entry

> The database is down because someone deployed at 4:55 p.m. on a Friday. It was me. I have learned nothing.

## Run

```sh
python3 main.py
```

Prints the line and writes it to `/output/entry.txt` (106 characters, one line).
